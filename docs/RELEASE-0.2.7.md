# Paperwork PDF Studio 0.2.7

这是一个兴趣项目的阶段性版本，主要在 AI 辅助下完成。感谢愿意试用和提出意见；重要文档请保留原件。

## 本次改动

- 在「常用设置 → 界面动画」中增加应用内动画开关，默认开启并记住本机选择，不跟随 Windows 的动画偏好。
- 调整首页纸页动效；没有 WebGL 时仍可使用二维效果，打印和高对比度保持静态。
- 移动文字时只显示定位轮廓，松手后再显示字体栏；下方空间不足时改放上方。
- 减少水印设置栏在松手时的闪烁，并同步检查图片、签名和电子章的设置栏定位。
- 新增「极致压缩（阅读优先）」档位。它适合部分高分辨率扫描件，但属于有损压缩，不保证每份 PDF 都能减少 75%。

## 本机验证与边界

发布前通过了 TypeScript/Vite 构建、370 项前端测试（另有 2 项显式跳过）、x64 Rust 主宿主测试和原生支持库测试；也使用合成文档检查了文字、水印及媒体对象的拖动和压缩另存流程。两个正式 EXE 均核对了内嵌前端资源，x64 免安装程序实际启动并通过 stdio 返回了 0.2.7。

这些结果只是当前构建机和所用样本上的记录，不代表所有 PDF 或设备都已覆盖：

- ARM64 已完成构建和 PE 架构检查，未进行 ARM64 真机运行验收。
- 四个程序都没有嵌入式 Authenticode 发布者签名，SHA-256 校验不是发布者签名。
- 极致压缩可能改变细小文字、低反差内容或 OCR 转写结果。校对和归档请优先使用原件或无损档。
- 本次 GitHub 发布沿用已验收的本地 0.2.7 程序，没有重新修改程序代码或重新打包。
